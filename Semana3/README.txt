CajeroParquedero: 
Se tomó el mismo esquema utilizado del parqueadero anterior de esta manera tendríamos definido los valores de horas,minutos y como varía segun carro o moto. 
A este se le agregó un contador, para que dejara registrado si ingresaba un carro o una moto, así se llevaría un control de que Entre y Salga la misma cantidad de vehiculos. 
Como condición se dejó que solo se puede cerrar la caja cuando el parqueadero es = 0. 
Al finalizar y cerrar, este toma en cuenta las transacciones de salida (pagos) reaizados, según como iba saliendo cada vehiculo, para dejar un total de cuanto facturó.  

Piramide: 
En la piramide se tenian que definir los espacios (columnas) y las (filas); este solo necesita preguntar un valor en este caso ¿Qué tan alta quieres que sea la piramide?.
Al ingresar el numero, este daría la base, como es una piramide no puede ser par, por lo que su base siempre será la altura * 2 -1 para generar el impar. 
Luego se hace un repetir donde se definen los espacios, las columnas permiten que haga un espacio, siempre que no sea mayor al numero ingresado, si llega al numero coloca un asterisco
En la siguiente fila repite, pero esta vez resta Altura - fila y llegado al punto imprime un asterisco hasta que iguale el numero de filas +1.
